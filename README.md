# Project 06 - Version Control Infrastructure

## Objective
Manage infrastructure code using Git and GitHub.

## Tasks
- Initialize a Git repository.
- Track infrastructure code.
- Push code to GitHub.
- Create a feature branch.
- Make changes and commit them.
- Open a Pull Request.
- Merge the Pull Request.

## Tools
- Git
- GitHub
- VS Code

## Deliverables
- GitHub repository
- Pull Request link
- Screenshots of Git workflow

## Git Workflow

1. Create a feature branch from main.
2. Make infrastructure documentation or code changes.
3. Stage and commit changes.
4. Push the feature branch to GitHub.
5. Create a Pull Request.
6. Review and merge changes into main.

## Branch Strategy

- main: Stable project version.
- feature/add-project-details: Development changes.
